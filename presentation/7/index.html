Как работает backend

Следим за запросом

Путь создания метки

01 / ВХОД →

Получить запрос

Форма отправляет JSON через Nginx: фото, описание и координаты.

POST /api/animals · /api/lost_ads
02 / ОГРАНИЧЕНИЕ →

Проверить частоту

Flask-Limiter считает запросы в Redis: до 30 в минуту на endpoint и IP.

Превышение → 429
03 / ВАЛИДАЦИЯ ↓

Проверить данные

JSON-объект, обязательные поля, формат времени и даты, допустимые координаты.

Некорректные данные → 400
04 / ЗАПИСЬ →

Сохранить в PostgreSQL

psycopg выполняет параметризованный INSERT в animals или lost_ads.

Транзакция · INSERT … RETURNING *
05 / ОТВЕТ →

Вернуть результат

Запись преобразуется в JSON; дата создания — в ISO-строку. Клиент получает результат.

Создано → 201 + JSON
06 / ОТОБРАЖЕНИЕ

Обновить карту и список

Frontend показывает данные API. Поиск по адресу и географическая фильтрация выполняются в браузере.

GET /api/animals · /api/lost_ads
404 запись не найдена503 база временно недоступнаPATCH / DELETE меткиDELETE объявления
