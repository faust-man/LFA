# Презентация «Ищу/Нашёл животное!»

Девять слайдов находятся в каталогах `1/` … `9/`. Общий стиль — `slides.css`,
управление и масштабирование — `presentation.js`.

После запуска проекта через `docker compose up -d --build` откройте
`/presentation/` на том же адресе, что и основной сайт. Для существующего
запуска после добавления папки и тома пересоздайте Nginx:

```powershell
docker compose up -d --no-deps --force-recreate nginx
```

- Пробел, стрелка вправо или PageDown — следующий слайд.
- Shift+Пробел, стрелка влево или PageUp — предыдущий.
- Home / End — первый / последний; кнопки снизу работают на сенсорном экране.
- Кнопка ⛶ включает полноэкранный просмотр, если браузер поддерживает его.
- Ссылка `/presentation/#6` открывает сразу шестой слайд с действующим сайтом.
- На телефоне сохраняется та же композиция; в портретной ориентации полотно
  поворачивается на 90°, в горизонтальной — масштабируется по экрану.

Содержание меняется только в HTML, редактирования на сайте нет:

- `1/index.html` — название проекта и учебного заведения (элемент `.school`).
- `2/index.html` — ФИО в `<h3>` и описание роли в `<p>` каждой карточки.
- Для фотографии замените содержимое соответствующего `.photo` на
  `<img src="photo-1.jpg" alt="Фото участника 1" />` и положите изображение
  рядом с `2/index.html`. Для остальных участников используйте свои файлы.
  В HTML есть комментарии с примерами для всех четырёх карточек.

После сохранения файлов обновите страницу. Данные из localStorage больше
не используются. В полях форм встроенного сайта пробел по-прежнему вводит текст.

Шестой слайд встраивает основной сайт через iframe с адресом `/`, без копирования
или изменения frontend. Функции карты требуют доступности существующих
внешних сервисов, а чтение и сохранение объявлений — работающего backend.

Таблица аналогов основана на предоставленном исследовании команды. Предложения
развития отделены от уже реализованных функций.

## Новые слайды и управление на телефоне

- `3/index.html` — четыре фотографии для рассказа об идее. Замените
  `cat-1.webp`, `dog-1.webp`, `cat-2.webp`, `dog-2.webp` в папке `3/` на свои
  фотографии или измените `src` в HTML. Текущие фотографии — реальные случаи из публичных объявлений Pet911; ссылки приведены на слайде.
- `8/index.html` — таблица 3×3. Названия перспектив находятся в `<h3>`,
  описания — в `<p>` внутри девяти `<td>`. Ввод на сайте не предусмотрен.
- На телефоне касание левой половины физического экрана возвращает слайд
  назад, правой — переключает вперёд. Это работает и при повороте полотна
  в портретной ориентации, и поверх встроенного сайта; в этом режиме
  касания предназначены для навигации по презентации.
